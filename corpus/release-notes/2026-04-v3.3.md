# Release 3.3

Released 7 April 2026

## New

- **Segments from respondent attributes.** Build segments from any attribute you pass via
  the API or a CRM integration, then filter dashboards and alert rules by segment.
- **Volume alerts.** Pulse Alerts can now warn you when response volume drops below a
  threshold.

## Improved

- The in-app SDK for iOS now supports SwiftUI natively.
- Exports of more than 50,000 responses are generated in the background.

## Fixed

- SAML logins failed for some Okta tenants that sent the email attribute in a different
  case. Emails are now compared case-insensitively.
- The HubSpot beta integration no longer creates duplicate contacts when an email has
  trailing whitespace.
