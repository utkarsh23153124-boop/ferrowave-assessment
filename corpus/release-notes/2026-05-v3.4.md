# Release 3.4

Released 19 May 2026

## New

- **Webhook signatures version 2.** Webhook requests now carry a `Pulse-Signature` header
  containing a timestamp and an HMAC-SHA256 signature. Version 2 protects against replay
  attacks. See the Webhooks article for verification steps.
- **Rate limit headers.** Every API response now includes `X-RateLimit-Limit`,
  `X-RateLimit-Remaining`, and `X-RateLimit-Reset`.

## Deprecated

- **Webhook signatures version 1** (`X-Pulse-Signature`, HMAC-SHA1) are deprecated from
  this release. They continue to be sent alongside version 2 for endpoints created before
  19 May 2026. Endpoints created after this date receive version 2 only. Version 1 will be
  removed in release 3.6.

## Improved

- Pulse Signals theme labels are now shorter and more consistent between runs.
- Scheduled exports to SFTP support key-based authentication.

## Fixed

- The web embed did not respect `prefers-reduced-motion`.
